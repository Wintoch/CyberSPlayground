### 1. dnsSpoofingwithScapy
This is my first small project created to learn more about how network layers work under the hood. I wanted to see for myself if I'm able to trick my own device into rerouting me to a different site than intended (combining ARP spoofing, DNS spoofing, and a local Flask server for redirection, all running concurrently via Python's `multiprocessing`).
